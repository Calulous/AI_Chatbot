# AI Chatbot

A simple AI chatbot built using **Python (Flask)**, **HTML**, **CSS**, and **Vanilla JavaScript**.

## Features

- AI-powered chatbot
- Multiple chat sessions
- Conversation history
- New Chat & Clear Chat
- Typing animation
- Error handling

---

## Installation

Clone the repository:

```bash
git clone <https://github.com/Calulous/Advanced-AI->
```

Install the required packages:

```bash
pip install -r requirements.txt
```

---

## Running the Application

Start the Flask server:

```bash
python app.py
```

Then open your browser and go to:

```
http://127.0.0.1:5000
```

---

## OpenAI API Key

The API key used during the technical assessment has **been included** in this repository.

If the original key has expired or been disabled, please replace the API key in `app.py` with a valid OpenAI API key before running the application.
